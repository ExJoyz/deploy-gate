How the gate works

  1. Add checklist items to a release and check them off as work lands.
  2. Checked items move to Completed; unchecked stay in Pending.
  3. The Deploy button stays disabled until every item is checked.
  4. Even then, deploy only proceeds after Kane CLI verifies the app end-to-end (npm run gate). If Kane fails, the deploy is blocked and a kane-report.md is written instead.
